# Завдання: Вимірювання часу спрацювання реле

Під'єднати реле до ESP32 та виміряти механічну затримку його спрацювання:

Один пін GPIO керує обмоткою реле (через транзистор).
Інший пін GPIO зчитує стан «сухого» контакту реле (режим INPUT_PULLUP).
Для вимірювання часу використовується millis() та переривання (attachInterrupt).
Враховано механічний брязкіт контактів при спрацюванні переривання.
Провести не менше 10 вимірювань, вивести результати в Serial Monitor та порахувати середній час увімкнення/вимкнення.
